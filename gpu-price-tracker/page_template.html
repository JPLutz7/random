    Price over time — across providers

    Sources

    Every number on this page comes from one of these. Nothing is scraped from a marketing page and nothing is estimated.

    Price feeds — the data itself
    • Oracle — OCI price list API, no authentication: apexapps.oracle.com/pls/apex/cetools/api/v1/products
    • Microsoft Azure — Retail Prices API, no authentication, api-version=2023-01-01-preview: prices.azure.com/api/retail/prices (reference)
    • Google Cloud — Cloud Billing Catalog API, service 6F81-5844-456A (Compute Engine), free API key: cloud.google.com/billing/docs/reference/rest/v1/services.skus/list
    GPU counts per machine — Azure prices whole machines, so turning a price into dollars-per-GPU needs a chip count, and the price feed does not carry one. Every count below was read from Microsoft's own published size table.
    • V100 — NCv3 (1 / 2 / 4 / 4; retired 2025-09-30 but still priced)
    • T4 — NCasT4_v3 (up to 4)
    • A100 — NC A100 v4 (1 / 2 / 4) · NDasrA100 v4 (8)
    • H100 — NCads H100 v5 (1 / 2) · ND H100 v5 (8)
    • H200 — ND H200 v5 (8)
    • MI300X — ND MI300X v5 (8)
    • GB200 — ND GB200 v6 (4 per VM, not 8 — the NVL72 rack is 18 VMs × 4)
    • RTX PRO 6000 — NC RTXPRO6000BSE v6 (fractional: 1/4, 1/2, 1, 2)
    • A10 — NVadsA10 v5 (fractional: 1/6, 1/3, 1/2, 1, 1, 2)

    Three entries are not backed by a published table and are marked as such in providers/azure.py: ND40s_v2 and ND40rs_v2 (V100), and the ND96ams / ND96amsr_A100_v4 80 GB sizes. They follow the documented sibling in their own series. Microsoft publishes no size table at all for NCads_A10_v4, so those machines are left blank rather than guessed.
